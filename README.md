# BOAT AI LAB

大村の出走表・展示情報と、端末内に保存するペーパーテストの記録アプリです。
自動予想モデルは未実装です。

## 今回追加した機能

- **過去検証**：出走表・結果がそろうレース数、締切前に6艇分の展示を保存できたレース数を表示。
- **固定ルールの比較**：3連単「1-2-3」と「全国勝率の高い順」を、同じ対象レースで1点100円として再集計。全期間と直近20%の開催日を切り替え可能。
- **公式結果との照合**：「結果入力」で、大村・3連単の的中一致をプレビューし、100円あたりの公式払戻を購入額に応じて保存。すでに確定した記録は上書きしません。
- 推定確率の初期値10%が入力ステップに合わず記録できなかった問題を修正。

### 検証の読み方

過去に取得した出走表による参考検証です。締切前に保存した予想の実運用成績ではありません。全国勝率が同じ場合は艇番順です。学習や結果を用いたルールの調整は行っていません。展示・気象・別途収集したモーター履歴は今回の比較に使いません。モーター番号だけで異なる使用期間の履歴を結合する処理もありません。

**結果CSVには返還情報がありません。** 固定ルールの回収率は返還未反映の参考値です。着順不一致の買い目は、返還対象でも支出100円・払戻0円として仮計算しています。正式な回収率ではありません。自動照合でも不一致を不的中に確定せず、返還の有無を公式で確認したうえで手動入力します。2連単・3連複の払戻も手動入力です。

6艇・6選手がそろわない出走表、結果の重複・不正、全国勝率の欠損は検証から除外します。締切前展示の件数は日別履歴も確認し、時刻が締切より前で、6艇分の公開済み展示と選手名が一致する場合だけ数えます。この件数だけで、全特徴量の締切前保存を証明するものではありません。

## 集計の再生成

追加のPythonライブラリは不要です（Python 3.11以上）。

```bash
python build_validation.py
```

- `data/validation_summary.json`：画面表示用の件数、期間、参考成績、入力CSVのSHA-256。
- `data/validation_races.csv`：各レースの正解、払戻、2ルールの買い目と取得時刻に関するフラグ。

入力・集計内容が同じ場合は集計時刻を維持します。3つの収集ワークフローがCSVを保存する前に再生成するため、収集の進行に応じて集計も更新されます。収集対象のない日や欠落した日は検証に含みません。日付範囲内の全レース収集完了を保証する表示ではありません。

## ローカル表示

リポジトリを静的HTTPサーバーで配信してください。GitHub Pagesでは更新の遅延を減らすため元リポジトリの `main/data/` を読み込み、それ以外では配信元の `./data/` を読み込みます。記録は配信元ごとに端末の `localStorage` に保存され、サーバーへ送信しません。

「成績」からCSVを出力して定期的にバックアップしてください。
